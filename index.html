第 I 章

強み

長く任せてもらえること、作る前から入れること、AIを道具として使いこなすこと。この三つを大事にしています。

  1. 長く任せられる

    同じお客さまの開発を、2021年から5年以上続けています。一括査定のシステムから始まり、今は不動産会社向けSaaSを担当。新しい機能づくりから不具合の修正、小さな改善まで、システムを育て続けるのが得意です。

  2. 「何を作るか」から入れる

    PM兼プログラマーとして、要件定義・設計から実装・運用まで担当してきました。業務側と確認事項を詰めて要件を決め、画面のモックで形を見せてから作ります。エンジニアでない人向けの説明資料も書きます。

  3. AIで速く、確かに

    生成AIを組み込んだ機能づくりと、Claude Code を使った毎日の開発の両方をやっています。AIに任せる範囲と人が確かめる範囲を決めて、速さと品質を両立します。

不動産会社向けSaaS · 2026

物件の資料を、AIが読んで自動で登録

工夫したところ

  • AIの混雑時は待ってやり直し、残高切れとは分けて通知
  • トークン数と時間を記録してコストを見える化。資料の中身はログに残さない

第 III 章

大事にしていること

  1. 使う人の困りごとから考える

    作る前に「何に困っていて、何があれば楽になるか」を一緒に整理します。

  2. 止めないための決まりを作る

    大きなテーブルを変えるときの決まりをチームで作り、デプロイ中もサービスを止めないように運用しています。

  3. 軽いテストで長く守る

    実際の操作に沿ったテストが中心。ブラウザで操作したログから、AIにテストを書かせる流れもチームで整えました。

  4. コメントには「なぜ」を書く

    次に読む人が、同じ判断をできるように。
